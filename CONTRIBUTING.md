# Contributing

- Open an issue first for anything larger than a bug fix.
- Every bug fix needs a regression test in `tests/`.
- Run `pytest -q` before opening a PR.
- Commit subjects: `fix: ...`, `feat: ...`, `test: ...`, `docs: ...`.
- Use the PR template.

## Developer Certificate of Origin

All commits must be signed off (`git commit -s`) per https://developercertificate.org.
PRs with unsigned commits fail the DCO check and will not be merged.
